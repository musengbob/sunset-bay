SUNSET BAY is an original open-world crime game: a sun-soaked coastal city to explore on foot and by car, with traffic and pedestrians, cars to steal and drive, a wanted level with police who respond, missions and a story, combat, a HUD with a minimap, a start screen and a save. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

All city, characters, vehicles, names, story, art, sound and music are original — nothing from any commercial game. The game runs offline from its own static files: no build step, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

## Controls

- WASD — move / drive
- Mouse — look
- E — enter / exit a car, steal a car
- Space — handbrake / jump
- F — punch / shoot
- R — start the next mission
- M — mute, P — pause, Esc — menu
